# COSMOS GUIDE — локальный прототип (без production deploy)

Это **локальная версия мобильной фото-навигации**. Содержимое `data/route.json`, исходные фото и стрелки **не изменялись**. Стартовый экран, 3 проверки формы и десктопная навигация сохранены.

## Что изменилось
- На экранах до 760 px: фото занимает максимум доступной высоты без обрезки (`object-fit: contain`).
- Верхняя панель: COSMOS, прогресс, аудио, сворачиваемое меню всех шагов.
- Внизу: компактное название шага, действие и две кнопки «Назад / Далее».
- Кнопка `i` показывает дополнительные инструкции, текст для охраны и номера супервайзера.
- Голосовой режим озвучивает текущий шаг и следующие при переходе. Требует поддержки `speechSynthesis` и русского голоса в браузере; **не гарантирует офлайн-аудио**. Реальные MP3 нужны для гарантированной работы без сети.
- На первом и последнем шаге кнопки корректно отключены. Фото открывается крупно по нажатию, свайп по изображению перелистывает шаги.

## ВАЖНО: фотографии и шрифты
В переданных файлах не было 10 оригинальных JPEG-фотографий и 6 локальных шрифтов `.woff2`. **Мы не заменяли их изображениями ИИ.**

1. Скопируй **целиком** папки `assets/images` и `assets/fonts` из своего текущего работающего проекта в этот каталог (сохранением названий).
2. Если их нет — запусти `get-assets.command`, который попробует скачать оригинальные изображения и шрифты с действующего GitHub Pages (нужен интернет). После загрузки проверь, что фотографии совпадают с оригиналами.
3. Запусти `open-route.command` или из папки проекта: `python3 -m http.server 8123`. Открой `http://127.0.0.1:8123/`.
4. Выбери 3 пункта формы, начни маршрут. На телефоне (или в мобильном режиме DevTools) включится COSMOS GUIDE.

Не запускай через двойной клик по `index.html` для полноценной проверки PWA: `file://` блокирует загрузку шрифтов и манифеста.

## Риски / ограничения
- На GitHub Pages этот архив **не загружался**. Публикацию производить только после проверки всех фотографий, шрифтов и 10 шагов на реальном телефоне.
- На iOS/Android браузеры и ОС по-разному поддерживают Web Speech; звук может требовать повторного нажатия, русский голос может отсутствовать, офлайн-TTS не гарантирован.
- Desktop интерфейс остаётся прежним; новый фото-режим активен только до ширины 760 px.
- При дальнейшем деплое сохранять `assets/images`, `assets/fonts` и проверять PWA Service Worker и обновление cache версии.

### Изменённые файлы
`index.html`, `css/app.css`, `js/main.js`, `sw.js`, `manifest.webmanifest.json`.

Все файлы в архиве можно накладывать на текущую локальную копию проекта, не удаляя существующие `assets/`.
