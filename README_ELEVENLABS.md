# COSMOS GUIDE · ElevenLabs MP3 · локальный пакет (НЕ ДЕПЛОЙ)

Набор из 10 MP3 записей **Stanislav — Deep, Empathetic and Warm**, нарезанных из одного предоставленного пользователем файла (147,07 с). Границы определены по длинным паузам. **Перед публикацией прослушайте начала и концы всех десяти фрагментов**: автоматическая нарезка не подтверждает точный смысловой переход.

## Что изменено

- `assets/audio/step-01.mp3` … `step-10.mp3` — отдельные записи для 10 экранов.
- `js/main.js` — вместо браузерного TTS воспроизводит соответствующий MP3. При переходе шагов прекращает предыдущий. При отсутствии MP3 пробует старый голос браузера.
- `sw.js` — новый `green-route-v56`, прекеширование аудио для офлайна и корректная обработка HTTP Range (`206`) для Safari/iOS.
- `index.html` — версия скрипта `v54` (CSS остаётся `v4`).

## Как применить к проекту на Mac

1. **Сохранить резервную копию** текущего проекта и запомнить последний рабочий commit.
2. Открыть свой АКТУАЛЬНЫЙ проект COSMOS Route, где уже присутствуют реальные `assets/images` и `assets/fonts`.
3. Скопировать файлы этого пакета поверх одноимённых путей **с объединением папок**, не удаляя другие ресурсы. Не нужно удалять `assets/images`, `assets/fonts`, `data`, `icons` или CSS.
4. Запустить локальный HTTP сервер (`open-route.command`). Нажать на все три чекбокса формы, открыть маршрут, включить наушники.
5. Пройти все 10 шагов и проверить что у каждого своя запись; переключение шагов останавливает прошлую; повторное нажатие выключает аудио.
6. В DevTools → Application → Service Workers / Cache Storage проверить `green-route-v56-shell` и наличие десяти MP3. После первоначальной загрузки отключить интернет и проверить несколько шагов и звук, в том числе на телефоне.
7. **Публикация не выполнялась.** Только после локальной проверки и отдельного решения владельца.

## Важно

- Для полного PWA офлайн-аудио нужны корректные файлы в `assets/audio`, успешное прекеширование и достаточное свободное место на телефоне.
- На iPhone браузер может требовать нажатия для начала воспроизведения; автостарт при переключении шагов может зависеть от правил устройства.
- При проверке на разных устройствах учесть `Audio()` и `speechSynthesis` fallback.
- Используйте наушники только если они не мешают слышать окружающую обстановку и указания персонала.
