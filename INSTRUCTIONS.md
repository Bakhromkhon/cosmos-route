# COSMOS Route — исправление загрузки

**Что исправлено:** в `index.html` добавлен атрибут `id="viewer"` к контейнеру маршрута. Он необходим для `document.getElementById("viewer")` в версии `js/main.js?v=52`.

**Как применить:**
1. Распакуйте архив.
2. Замените ТОЛЬКО файл `index.html` в корне исходного проекта на файл `index.html` из архива.
3. Оставьте папки `assets/`, `css/`, `data/`, `icons/`, `js/` и все остальные файлы проекта без изменений.
4. Откройте `index.html` заново. Для веб-версии обновите соответствующий файл в репозитории только после проверки локально; автоматический деплой здесь не выполнялся.

Примечание: если открываете `open-route.command` и macOS пишет Permission denied, в Терминале в папке проекта выполните `chmod +x open-route.command`.

Важное: в старой публичной версии GitHub Pages пока `js/main.js?v=51`, а в присланных файлах `v=52`. Не смешивайте версии при загрузке.
